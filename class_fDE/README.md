## Installation

CLASS_fDE follows the standard CLASS installation:

```bash
git clone https://github.com/GabrieleMonte/fDE_cosmo_public.git
cd fDE_cosmo_public/class_fDE
make
```

## Citation

This code is based on the theoretical framework developed in the following paper:

- G. Montefalcone, R. Stiskalek, *Parameterizing Dark Energy at the density level: A two-parameter alternative to CPL*, [arXiv:2603.25735](https://arxiv.org/abs/2603.25735)

Please cite this work if you use **class_fDE** in your research.
